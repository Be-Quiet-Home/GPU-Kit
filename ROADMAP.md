# Roadmap

See [docs/08_roadmap_milestones.md](docs/08_roadmap_milestones.md) for the detailed roadmap.

## Short version

```text
0. Document the idea.
1. Build repository skeleton.
2. Implement null backend.
3. Implement software backend.
4. Show first Haiku surface.
5. Show four-surface multimedia demo.
6. Add tracing and diagnostics.
7. Begin reference GPU research backend.
8. Perform first hardware clear/blit/present.
9. Add minimal native 3D.
10. Explore OpenGL/SDL compatibility layers.
```

## Current phase

Phase 0: documentation and architecture boundaries.

## Success definition

The first major success is not OpenGL.

The first major success is a native Haiku GPU/media path that can show multiple responsive surfaces with clear ownership, explicit capabilities, asynchronous command submission and no foreign public graphics model.
